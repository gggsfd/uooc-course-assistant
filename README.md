# UOOC 网课助手（优课在线）

优课在线（uooc.net.cn）网课页面的浏览器辅助脚本，纯前端运行，无需安装扩展。

## 功能

| 脚本 | 作用 |
| --- | --- |
| `keep-play.js` | 防暂停守护：鼠标离开播放器 / 窗口失焦 / 页面隐藏导致视频暂停时，自动恢复播放 |
| `quiz-bot.js` | 弹题机器人：视频中的小测弹窗出现时自动从第一个选项开始试答，直到通过；无选项的通知弹窗自动点“确定”；全部选项试完仍不对时闪烁标签页标题提醒人工处理 |
| `shade-cleaner.js` | 遮罩清理器：弹窗关闭后残留的 layui 黑色遮罩会层层叠加把页面盖黑，定期自动清除 |
| `auto-next.js` | 自动下一节：视频播完后自动进入同小节下一个视频 / 下一个三级小节（2.4.1 这类）/ 下一节 / 下一章；有三级小节的节自动跳过节自身的二级视频；自动跳过“章节测试”；连续失败自动退避，不会疯狂刷请求 |
| `install-all.js` | 一键安装：上面四个脚本的合并版，整段粘贴进控制台即可全部启动 |

## 使用方法

1. 用 Chrome / Edge 打开优课在线的课程学习页面，登录并进入任意一个视频小节。
2. 按 `F12` 打开开发者工具，切换到 **Console（控制台）**。
3. 把 `install-all.js` 的完整内容粘贴进去，回车运行。
4. 看到 `[UOOC助手] 全部脚本已启动` 即成功。刷新页面后需重新粘贴运行。

## 停止 / 排查

- 全部停止：在控制台执行 `__stopQuizBot()`
- 答题记录查询：控制台执行 `__quizLog`
- 弹题卡住时标签页标题会出现「【弹题卡住】」前缀，需人工答那道题

## 注意事项

- 仅支持视频内嵌的单选小测；多选 / 填空题机器人会自动停手提醒。
- 自动试答的错误选项可能被平台记录；章节测试等大考请自行作答。
- 选项顺序由平台随机打乱，本脚本与答案内容无关，仅自动化页面操作。
- 仅供学习交流使用，请遵守学校及平台的课程规定，使用风险自负。
